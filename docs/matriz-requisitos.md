# Matriz de requisitos e aceite

Cada requisito do mestre tem uma linha e evidência. “Parcial local” significa que apenas a fatia descrita foi executada em MariaDB 10.10.7; não equivale a sandbox, homologação ou produção. O banco de destino é MariaDB 10.10.7/InnoDB; os termos `provider = "mysql"` e `mysql://` são identificadores técnicos do Prisma/conector. Os 80 cenários seguem como requisitos, nenhum grupo foi aprovado por inferência.

## Comandos e evidências

- `npm.cmd run verify:m1`: evidência histórica anterior às migrations pedagógicas; duas escolas no mesmo schema e FK cross-tenant rejeitada. Consulte `prisma migrate status` para o estado atual.
- `npm.cmd run smoke:m1`: sessão/membership, dashboards nas duas escolas, projeção pública minimizada e vínculo familiar isolado.
- `npm.cmd run smoke:m2`: gestão escolar, isolamento familiar, paginação numerada de álbum e fila, filtros, decisões e histórico de revisão/versionamento; arquivos de bytes reais não testados.
- `npm.cmd run smoke:m2:lifecycle`: CSV/idempotência; transferência cross-tenant; conta nova pendente, reenvio seguro sem SMTP, confirmação válida e desafios expirado/revogado/reutilizado; senha de conta existente; limites de convite/login/envio/confirmação; onboarding/calendário/virada. Dados temporários limpos; sem entrega de e-mail real.
- `npm.cmd run smoke:m2:email`: três mensagens capturadas localmente em loopback; destinatário/conteúdo conferidos, tokens de reenvio diferentes, rate limits de envio/conclusão, confirmação concorrente com exatamente uma sessão/vínculo e invalidação dos desafios restantes. Sem tráfego de e-mail externo.
- `npx.cmd prisma migrate status`: 20 migrations; schema `_dev` atualizado.
- `npm.cmd run smoke:m3:evidence`: fallback local sem S3, bloqueio em quarentena com ClamAV ausente, liberação após revarredura TCP simulada, negações cross-tenant/família/vínculo revogado; fixtures e sessão limpos no `finally`.
- `npm.cmd run smoke:m3:workflows`: turma, plano/diário idempotente, pedido familiar, consentimento/revogação, encerramento pela escola, reabertura exigindo nova concessão e limpeza local.
- `npm.cmd run typecheck`, `npm.cmd run smoke:m3:workflows` e `npm.cmd run build` passaram nesta fatia. Smoke verifica T66 e T67 (privacidade e tipo de midia, feriado, chamada nao registrada/parcial/completa), alem do mural e consentimentos paralelos. Build de producao local passou. UI interativa do mural nao executada: CUA `Transport closed`, Playwright nao instalado. 20 migrations aplicadas; lint sem resultado.

Consulte `docs/execucao.md` para ambiente, migration, limitações e próximo passo.
